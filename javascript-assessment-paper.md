# JavaScript Assessment Question Paper

## Section A: Multiple Choice Questions (20 × 1 = 20 marks)

1. Which method returns a new array with elements that match a condition?
   - A. `map()`
   - B. `filter()`
   - C. `reduce()`
   - D. `forEach()`

2. What does `join("-")` do on an array?
   - A. Removes the first element
   - B. Converts the array to a string with `-` between elements
   - C. Sorts the array
   - D. Adds a new element

3. Which of these string methods removes whitespace from both ends of a string?
   - A. `split()`
   - B. `trim()`
   - C. `slice()`
   - D. `replace()`

4. What is the output of `"Hello".charAt(1)`?
   - A. `H`
   - B. `e`
   - C. `l`
   - D. `o`

5. Which keyword declares a block-scoped variable in JavaScript?
   - A. `var`
   - B. `const`
   - C. `let`
   - D. `function`

6. What does `Number.isNaN("abc")` return?
   - A. `true`
   - B. `false`
   - C. `undefined`
   - D. `NaN`

7. Which Array method transforms every element and returns a new array?
   - A. `filter()`
   - B. `map()`
   - C. `reduce()`
   - D. `find()`

8. What does `delete obj.prop` do?
   - A. Deletes the object
   - B. Removes the property `prop` from `obj`
   - C. Sets `prop` to `undefined`
   - D. Throws an error

9. Which method is used to replace all occurrences of a substring in modern JavaScript?
   - A. `replace()`
   - B. `replaceAll()`
   - C. `split()`
   - D. `substring()`

10. Which of the following is true about strings in JavaScript?
    - A. Strings are mutable
    - B. Strings are objects only
    - C. Strings are immutable
    - D. Strings can be changed by index assignment

11. Which method returns the length of a string?
    - A. `length()`
    - B. `size`
    - C. `length`
    - D. `count`

12. What will `"apple".toUpperCase()` return?
    - A. `apple`
    - B. `APPLE`
    - C. `Apple`
    - D. `aPpLe`

13. Which of these is a valid way to create a symbol in JavaScript?
    - A. `Symbol("id")`
    - B. `symbol("id")`
    - C. `new Symbol("id")`
    - D. `Symbol.create("id")`

14. What does `array.reverse()` do?
    - A. Returns a reversed copy
    - B. Sorts the array
    - C. Reverses the array in place
    - D. Removes the first element

15. Which operator is used to concatenate strings?
    - A. `+`
    - B. `&&`
    - C. `||`
    - D. `++`

16. What will `"Hello".substring(1, 4)` return?
    - A. `Hell`
    - B. `ell`
    - C. `ello`
    - D. `Hel`

17. Which statement is true about `const` in JavaScript?
    - A. The value can be reassigned
    - B. The variable cannot be redeclared or reassigned
    - C. The variable is function-scoped
    - D. It creates a global variable only

18. What does `array.some(fn)` check?
    - A. If every element passes the test
    - B. If at least one element passes the test
    - C. If no elements pass the test
    - D. If the array contains a specific value

19. What is the correct way to write a multi-line string using template literals?
    - A. `"Hello\nWorld"`
    - B. `
Hello
World
`
    - C. ``Hello
World``
    - D. `"Hello" + "World"`

20. If `x = 5`, what does `typeof x` return?
    - A. `number`
    - B. `string`
    - C. `object`
    - D. `undefined`

## Section B: Program Questions (5 × 6 = 30 marks)

### Question 1
Write a JavaScript program that:
- creates an array of five numbers,
- filters out odd numbers,
- doubles the remaining even numbers,
- and prints the final array.

### Question 2
Write a JavaScript program that:
- takes the string `"  JavaScript is fun  "`,
- trims the whitespace,
- converts the trimmed string to uppercase,
- and replaces the word `FUN` with `EASY`.

### Question 3
Write a JavaScript program that:
- defines an array of strings such as `["apple", "banana", "cherry"]`,
- joins the array into a single comma-separated string,
- converts that string to lowercase,
- and logs the result.

### Question 4
Write a JavaScript program that:
- uses a string like `"Hello World"`,
- accesses and prints the first, middle, and last character,
- then prints the string in reverse order.

### Question 5
Write a JavaScript program that:
- creates a simple object with at least three properties,
- deletes one property using the `delete` operator,
- and prints the object before and after deletion.
